# Weight Loss Percentage Calculator

Weight Loss Percentage is a free calculator suite that expresses body-weight change as a percentage of the starting weight. A percentage normalises progress across different body sizes, so a clinician, a parent and a dieter all read the same number the same way.

## What the suite calculates

| Tool | Input the tool accepts | Value the tool returns |
|---|---|---|
| Newborn weight loss calculator | Birth weight and current weight | Percentage of birth weight lost |
| Baby weight loss calculator | Birth weight and current weight | Percentage lost, week by week |
| BMR calculator | Age, sex, weight and height | Resting daily calorie burn |
| TDEE calculator | BMR inputs plus activity level | Total daily calorie burn |

## How newborn tracking works

Firstly, record the baby's birth weight. Secondly, weigh the baby again on the day of the check. Finally, enter both values in the [weight loss calculator newborn](https://www.weightlosspercentage.com/calculators/newborn-weight-loss/). The tool returns one percentage. A loss inside the normal first-week range needs no action. A loss outside that range tells the parent to call the clinician.

Parents who track an older infant use the [percentage weight loss calculator baby](https://www.weightlosspercentage.com/calculators/baby-weight-loss/) instead, because the baby tool compares each week against the expected regain pattern.

## Why percentage beats raw pounds

A ten-pound loss means one thing on a 280-pound frame and something different on a 140-pound frame. The percentage states both results on one scale. That comparability explains why clinics, neonatal units and weight-loss competitions all chart percentage first.
